
# JobPulse AI

An India-focused Job Market Intelligence Platform built using Python, Data Science and Machine Learning.

## Problem Statement

Students and job seekers often lack reliable insights into the skills, salaries and hiring trends demanded by the Indian technology job market.

JobPulse AI aims to analyze job-market data and provide actionable insights through data analytics, visualizations and machine learning.

## Planned Features

- Job market data analysis
- In-demand technical skills
- Salary distribution analysis
- Location-wise hiring trends
- Salary prediction
- Interactive analytics dashboard

## Technology Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- SQL
- Streamlit
- FastAPI
